# Flujos

1. El suscriptor identifica el RFC autorizado.
2. Sube un PDF/JPG/PNG o captura un QR/URL.
3. El sistema valida el dominio del proveedor y extrae datos como sugerencias con evidencia y confianza.
4. El usuario confirma los datos mínimos y autoriza una solicitud asistida o automática permitida.
5. El proveedor responde por integración autorizada, correo asociado o carga manual.
6. El sistema valida, deduplica, vincula XML/PDF, actualiza estado y notifica.

Para restaurantes, el enlace “Factura con YuppiFacts” debe transportar únicamente folio, sucursal, fecha, total y URL oficial con consentimiento. El tenant de restaurante y el del comensal nunca comparten datos fuera de una solicitud autorizada.
