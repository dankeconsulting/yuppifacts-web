# Auditoría de referencia Cobrix

Fecha: 18 de octubre de 2026.

Se revisó en navegador la landing pública `https://cobrix-frontend.vercel.app/`. Estructura observada: header pegajoso, hero en dos columnas, fondo casi negro, tarjetas de superficie oscura con borde tenue, radio grande, jerarquía tipográfica muy contrastada, listas verticales guiadas por una línea de acento, grid de funciones y CTA final. La navegación pública incluye cómo funciona, funciones, IA, documentación, acceso y demo.

Tokens aproximados recuperados visualmente: base `#090b0d`, superficies próximas a `#111419`, borde gris azulado cercano a `#242a33`, texto claro y acento verde. YuppiFacts conserva el sistema de composición y reemplaza el acento por morado (`#a78bfa`) como cambio de marca autorizado. No se copió código, contenido, identidad ni datos de Cobrix.

Las capturas adjuntas por la propietaria complementan la inspección: muestran landing, acceso y un dashboard con sidebar. Por limitaciones del entorno, no se exportaron archivos de imagen adicionales durante esta auditoría.
